# Security Policy

- **Reporting**: Report suspected vulnerabilities privately to _security@qbitflow.app_.
- **Supported Versions**: We support the latest minor release and the previous one.
- **Patch SLAs**: Critical issues patched within 72 hours; high within 7 days.
- **Disclosure**: Coordinated disclosure with CVE where appropriate; fixes are described in CHANGELOG.md and in GitHub security advisories.
- **Integrity**: Go module versions are immutable once published and verified by the Go checksum database (`sum.golang.org`); keep `GOSUMDB` enabled and depend on tagged versions only.
